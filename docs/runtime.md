# 仪表盘与代理组

## 数据与任务

- 参考 CV 的实际模式回读、代理组选择、独立节点测速、按订阅记录选择及有界流量采集。
- 内核就绪后，通过私有通信通道订阅 `/connections?interval=1000` 和 `/traffic` WebSocket；`/configs`、`/proxies`、`/providers/proxies` 每 5 秒回读。采集任务由应用持有，切换页面不中断。
- 内核代次和配置修订用于拒绝过期采集结果与节点操作；配置变化取消旧采样，退出时取消采集并保存统计。
- 错误通过 toast 和程序日志报告，保留完整界面；连续相同采集错误不重复报告。

## 仪表盘

- 模式、代理端口、活动连接与代理组使用内核回读；DNS 模式取回读或已加载配置。规则模式的策略节点沿配置中的首个代理组解析；全局模式沿 GLOBAL 解析，直连模式显示 DIRECT。
- 速率采用 `/traffic` 的真实 up/down；累计量和排行采用 `/connections`。计数器重置、内核重启和采集中断重新建立基线，不补造速率或流量。
- 速率图保留最近 120 个样本；中断后清除曲线，避免跨缺口连线。
- 出口请求耗时经实际内核 HTTP/混合端口请求设置中的测速地址，接受 204 空响应；不根据首个代理组猜测请求路由。外部 IP 每分钟经同一代理请求 IP 服务，失败后换源；无可用代理端口时不发起检测，不直连替代。
- 请求耗时与 IP 检测分别处理，保留具体失败原因。外部网络检测失败记为 Warning，内核采集及统计保存失败记为 Error；相同失败去重，使用 toast 提示。
- 今日、本月和小时流量表示已采集统计，不包含应用未采集的时段。连接分类、进程、域名和策略排行来自活动连接采样；采样间已结束的连接流量记为未分类。
- 小时统计保存到应用数据目录 `statistics/traffic.json`，每 30 秒及退出时写入，保留 35 天；排行有数量与文件大小上限，文件达到上限时保留累计量并释放排行明细。
- 统计文件读取失败时保留原文件，本次只在内存采集并提示错误。

## 代理组

- 使用实际代理组及成员、协议、延迟、当前节点、固定节点和隐藏状态。全局模式展示 GLOBAL，规则模式展示配置代理组，直连模式保留切换入口。
- Selector 选择以 `now` 回读确认；URLTest/Fallback 固定选择以 `fixed` 回读确认。固定节点和实际当前节点分别显示，恢复自动选择后确认固定值已清除。
- 节点选择在内核确认后记录到 `settings/settings.json` 的 `proxy_selections`，按订阅身份隔离；启动和订阅热加载后恢复。遵守内核页的「保存节点选择」设置。
- 保存失败不宣称内核操作已撤销；提示已经完成的操作和保存错误。
- 测速支持单节点、单组及全部组，使用设置中的 URL、超时和并发数。独立任务逐个调用节点 delay 或 Provider healthcheck 接口，避免组测速接口清除固定节点。按组与节点保存 30 分钟测量缓存、相同任务去重，总并发最多 10，不占用生命周期操作队列。组地址优先于全局地址，整批结束才更新排序。预置及未解析节点跳过。
- LoadBalance/Relay 不提供手动选择；链式代理按保存顺序生成 dialer-proxy，保存并应用后选择出口并确认，断开时从原始来源重新合成，不删除用户原有其他链路。
- 搜索、排序、展开和紧凑显示只保留在当前界面，不写入设置。

## 列表性能

- 日志、连接与规则使用原生 DataTable 的虚拟行/列。
- 订阅、覆写、代理组及节点、订阅增强、资源集合、WebUI、隧道、网卡信息和流量排行使用原生 VirtualList，只创建可见行。卡片按当前列数虚拟化，代理组和节点共用滚动视口，折叠使用原生动效。
- 领域身份、选择状态与滚动状态分别持有；宽度或 rem 变化重新计算行尺寸。数据行长文本截断，编辑入口保留完整数据。
- 实时流量变化不重复解码未变化的订阅来源，也不重建未变化的代理组。
- 固定表单字段、导航和操作栏继续使用对应原生控件；原生 Select、菜单和编辑器保留组件自身的列表与行管理。
- HTTP 使用 reqwest 类型化标头、代理与重定向策略；私有 IPC 使用 Hyper；WebSocket 使用 tokio-tungstenite。没有外部 curl 进程或配置字符串。

## 验证边界

自动化覆盖一万行可见范围、六百张订阅卡片的跨视口选择、204 请求及 IP 服务换源、类型化标头及敏感数据保护、计数差值、重复采样、代次变化、缺口、未分类流量、统计重读、代理解析、选择记录、采集取消、空状态与首个速率样本的原生布局。真实 Mihomo 测试覆盖选择、固定/取消固定、模式回读、模式保存、PID 不变、选择恢复、私有通道采样及本地 HTTP 测速。

具体回归结果和剩余差距见 [CV 对照清单](cv-gap-checklist.md)与[本轮实施记录](cv-implementation-progress.md)。实时规则主体和链式节点拖放已接入；完整平台服务、TUN、Provider 链实例化及 Windows/Linux 实机验收仍待完成。


## WebSocket 与连接

连接和流量任务由应用持有，最新帧 watch 有界合并，界面每 200 ms 发布。断线按 250 ms 至 5 s 退避重连，15 s 无数据标记失效；Ping/Pong 不代替业务数据。目标、密钥、代次或配置修订变化关闭旧流，正常关闭预算 250 ms，退出等待并取消未结束任务。

连接页显示实际连接、速率、进程、地址、规则和代理链；保留最多 1000 条已关闭记录。暂停只冻结显示，仍继续跟踪。断流保留数据并标记待确认，禁用关闭；单项与全部关闭经真实 DELETE 后 GET 回读确认。历史与选择使用稳定身份，实时更新不滚回选中行。规则页仍未接入完整实际业务。

## 图标与错误

代理组的 HTTP(S)、data 图片和内嵌 SVG 在后台校验后写入内容哈希缓存；限制 2 MiB、4096 像素边长和解码分配。SVG 移除外部图像引用，位图规范化为静态 PNG，不在渲染中下载或读取磁盘。正常缓存加载只记 Debug，错误使用 toast；图标失败不影响组的展开、选择与测速。

并行检测和换源错误按原因合并，例如“出口请求、出口 IP 检测：HTTP 连接失败”，不重复嵌套原因。不同恢复步骤的失败和已提交事实保留。详细网络边界见 [network.md](network.md)。

链式设置采用 settings/settings.json 的 proxy_chain 分组的原生布尔、节点数组和自定义 proxies 对象；首次缺失生成默认值，无旧文件读取或迁移。自定义 proxies 顺序作为多节点链输入。停止时只保存；运行时校验、热应用、选择出口和回读，失败恢复旧配置。断开清理实际连接并回读；启动时恢复启用链的出口。

自定义代理配置按结构化 JSON 对象保存，编辑器使用 YAML 显示；不把多节点编码为换行字符串。文件沿用私有目录与临时文件权限，不在日志、toast 或诊断中输出配置正文和节点凭据。
