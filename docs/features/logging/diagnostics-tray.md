## 诊断包

原先仅输出设置检查结果和文件大小，无法判断实际开启的 DNS、TUN、控制端口及程序偏好。现在额外输出 `configuration/` 下的实际文件脱敏副本：

- `settings/settings.json`：完整程序设置分组，包括通用／外观、系统代理、内核、DNS、嗅探及备份偏好。
- `settings/mihomo.yaml`、`dns.yaml`、`sniffer.yaml`：实际持久化的内核原生设置。
- `settings/settings.json`：订阅元数据和代理选择；`indexes/`：覆写索引和订阅增强。当前格式中增强片段为 YAML 字符串，先按其已定义格式处理，再写回脱敏 JSON。
- `profiles/`、`overrides/`：订阅和 YAML 覆写；安全凭据文件与任意 JavaScript 正文不进入包。
- `runtime/`：当前可读取的本地 `core/run-*/candidate.yaml`；另包含存在时的 `runtime-source.yaml`。不越权读取系统服务的受限目录，不把本地候选文件描述为内核 API 的实际回读。

配置脱敏在 ZIP 写入前完成。保留开关、端口、列表顺序和非敏感字段；遮蔽密码、Token、鉴权、自定义请求头、私钥、UUID、代理服务器、订阅 URL 的私有路径／参数，以及应用和用户目录。代理 URI 可能把凭据整体编码在 URL 的 host 部分，因此非公共网络／DNS URL 的地址整体遮蔽。安全凭据库不读取，源文件不改写。

格式损坏的 JSON／YAML 不按其他格式重试：保留行数、空白和结构标点，其余字符掩码，文件名追加 `.redacted.txt`；`environment.txt` 记录原错误位置。单文件超过 8 MiB、总读取超过 32 MiB、普通文件读取失败或符号链接均记录原因，其他文件继续导出。设置和候选配置优先于大订阅，避免订阅占满限额后丢失核心设置。日志仍只导出本次运行登记的文件及内存尾部。

## 三端托盘

三端采用原生托盘图标加 GPUI 轻量级联浮层。macOS 使用 AppKit 状态项，Windows 使用 Win32 状态图标，Linux 使用 zbus 的 StatusNotifierItem（包含 ContextMenu 回调）。菜单使用原生虚拟 List 和 Base Positioner，以支持大量节点及屏幕边缘翻转，不修改依赖。

主菜单依次提供出站模式、订阅、带 Network 图标的“代理组”、系统代理及虚拟网卡等操作；具体组名只在代理组子层展示，仅显示已配置的自定义图标，组内节点不显示图标。目录／日志入口及对应托盘执行逻辑全部删除，已无意义的代理组布局设置一并删除。浮层不透明度为 96%，纯色模式完全不透明；透明宿主不启用整屏模糊。窗口尺寸不随实时刷新变化，保留滚动和选中身份。

macOS 真实窗口已展示轻量菜单与长节点子层；Windows 和 Linux 尚未进行桌面实机验收。Wayland 依赖 Layer Shell 定位，不支持时报告原因，不自动打开主窗口。

Windows 曾使用 HMENU，超长菜单滚动箭头在用户机器上保留白底，`SetWindowTheme` 方向实测无效。当前 GPUI 浮层已替换该菜单；不再维护原 HMENU 主题 hook。原生图标仍由系统承载，浮层需要实机核对多屏、DPI、屏幕边缘、点击外部关闭及焦点恢复。

诊断包后续调整：删除独立的 `settings-check.txt`、`files.txt` 和两个 `export-status.txt`。保留脱敏配置和日志，说明与错误状态集中到 `environment.txt`。环境内容扩展为系统版本、CPU、内存、GPU、磁盘、网卡、DNS、默认路由、进程基本信息、应用目录及当前应用进程完整环境变量；使用 `sysinfo 0.40.0` 和 `netdev` 的当前 API，不读取其他进程的命令行、环境或安全凭据库。
