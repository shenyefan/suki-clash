# 规则、覆写、DNS 与嗅探

更新日期：2026-10-28。以当前工作区为准。

## 规则

通过内核私有通道读取 `/rules`，保留原始顺序、重复条目和未知规则类型。快照绑定内核代次与配置修订；启动、切换和热加载后重新读取，也支持手动刷新。刷新失败保留上次数据并通过 toast 提示；停止或规则修订未确认时显示对应状态。

界面使用原生虚拟表格，提供类型筛选、关键字/大小写/整词/正则搜索、排序、复制及底部详情。排序与筛选为会话状态；刷新保留相同修订中的选中身份和滚动位置，修订变化清除旧详情。规则集合更新仍位于外部资源页面。内核未提供逐规则命中次数，不生成命中统计。

## 覆写

YAML 与 JavaScript 按保存顺序执行；只应用已启用且匹配当前订阅作用域的记录。编辑、开关、排序、删除、撤销和远程更新统一由内核生命周期执行端串行提交，使用预期索引拒绝真正过期的请求。界面从同一执行端读取最新提交索引，不使用旧存储缓存作为下一次请求的版本。

运行时先合成候选配置、使用目标内核校验、热加载并回读，再提交正文、索引与运行文件。失败恢复旧文件与运行配置；恢复失败单独报告。停止时只校验来源格式并保存，不启动内核。页面没有“应用覆写”按钮，整行拖拽调整执行顺序。内核拒绝后保留界面草稿供修正，重新打开读取已提交值。

远程 YAML/JavaScript 使用共享下载服务，支持直接导入、自动名称、User-Agent、鉴权、Age、超时、手动和定时更新。间隔 0 关闭，大于 0 按最后成功更新时间调度；失败按间隔重试。批次逐项提交，失败项保留旧内容。下载进度使用持续 toast。覆写凭据与订阅使用独立的安全存储命名空间。

删除后可在当前会话撤销，恢复顺序、正文和凭据；撤销材料限制为 128 项及 8 MiB 正文。界面编辑器提供语法检查、复制及模板重置；草稿保存仍属于用户数据提交，与设置页自动保存分开。

JavaScript 使用 [rquickjs 0.14.0](https://docs.rs/rquickjs/0.14.0/rquickjs/struct.Runtime.html)，不暴露文件、网络和进程 API。调用 `main(config, name)`，输入和名称通过参数传入；必须同步返回可序列化对象。脚本默认 5 秒、64 MiB 引擎内存、512 KiB 栈；引擎中断同时检查截止时间和任务取消，不以停止等待代替停止执行。配置合成运行于后台阻塞任务，取消后释放执行资源。

每次脚本保留最多 256 条、64 KiB 日志。执行失败不跳过脚本；异常正文不直接输出，已知配置凭据及含地址日志脱敏。最新执行记录写入 `logs/overrides/<id>.json`，最多保留 128 个文件；“执行日志”读取真实报告。脚本结果仍受配置大小、深度和节点预算限制，控制通道保护在合成末尾执行。

## DNS

表单与 YAML 共用一个文档，支持 DNS、Hosts、服务器、Fake-IP、解析策略和未知内核字段。原生 YAML 文件是唯一持久化来源，不重复保存表单字段。表单文本失焦提交，开关和枚举立即提交；YAML 失焦校验并提交。停止时仅保存；运行时通过统一候选配置工作流热加载，失败保留旧设置和配置。

`settings/dns.yaml` 仅保存原生 DNS 和 Hosts；全局启用开关保存在 `settings/settings.json` 的 `dns.dns_override_enabled`。切换订阅共用同一份设置，不维护按订阅开关或来源确认。合成顺序为订阅及增强 → 全局 DNS → 有序覆写；指定订阅的 DNS 差异通过覆写作用范围实现。关闭全局 DNS 时保留文件内容，直接继承订阅与覆写；切换和启动不自动改变开关。

不读取、生成、迁移或删除原有按订阅 DNS 偏好文件。


## 嗅探

支持启用、目标覆盖、DNS 映射、纯 IP、HTTP/TLS/QUIC 端口与范围、域名及来源/目标 IP 过滤。表单和完整 YAML 共用文档；编辑已知字段保留未知协议和协议子字段。原生端口保存为数字，范围保存为文本；多值设置为 YAML 序列。

`settings/sniffer.yaml` 仅保存原生 `sniffer` 文档；总开关保存在 `settings/settings.json` 的 `sniffer.sniffer_override_enabled`。关闭覆写继承订阅，开关值和编辑内容仍保留。保存、校验、热应用与失败恢复采用与 DNS 相同的工作流。

## YAML 布局

同一文件包含多个表单 Tab 时，YAML 模式隐藏分类 Tab 和列表搜索/筛选，保留页面标题；模式切换位于底栏右侧，弹窗在取消左侧。编辑器占满剩余内容宽高，不使用固定短高度；编辑器负责自身滚动，外层不再滚动。切回表单恢复分类选择。

已核对 DNS、嗅探、订阅增强、订阅/覆写全文编辑器。单字段多行输入保留有界高度。代理链 YAML 按 CV 编辑完整 proxies 序列，与可视列表双向同步节点内容和顺序，使用完整编辑视口。
