# Gist 完整备份

状态更新（2026-11-09）：用户确认文档此前列出的实机验收部分均已完成，相关待验收项关闭。下文各次检查中的“未验收／待验收”保留为当时记录；本次未重新运行验收。实现范围、暂缓项及能力限制以[当前功能对照](../../reference/cv/cv-gap-checklist.md)为准。

设置 → 同步 → Gist 备份提供配置、创建备份和历史入口。使用GitHub Token（gist权限）；Token和可选Age私钥通过独立的系统安全凭据账号保存，不写入普通设置或归档。备份加密开关／公钥保存于settings/settings.json的backup分组。文本失焦保存、开关立即保存；空凭据输入保留原值，明确清除动作延迟5秒并可撤销。

每次创建生成新的secret Gist，保留独立历史；历史按GitHub用户Gist原始分页读取，再筛选本应用备份文件，仍可向后翻页。可下载原始归档，或恢复、删除。删除和恢复先等待5秒，toast可撤销；恢复另有确认框。失败保留现有历史和编辑草稿，不自动重复创建或删除。下载／远程操作沿既有持续进度toast，结束后关闭；不将HTTP失败当作成功。

归档包含当前格式的settings原生YAML／程序JSON、订阅元数据与节点选择、indexes覆写索引及增强、profiles与overrides正文；不包含核心、资源缓存、日志、OS服务注册或凭据库。本机同步／备份配置与GUI登录注册不参与跨设备覆盖。普通未加密归档仍包含代理及来源内容；需要隐藏内容时启用Age并单独保管解密私钥。

文件ZIP带当前版本manifest和逐文件SHA-256摘要，再以文本承载；可选Age公钥加密。压缩前总文件上限32MiB，远程编码归档上限8MiB（本地文件编码上限48MiB），解压数量、总量、路径、文件类型、摘要与格式统一校验，拒绝目录穿越和符号链接。无旧格式兼容／迁移／回退读取。API正文截断时使用GitHub返回的受限raw_url读取，无API令牌转发到raw请求；依据[GitHub官方Gist文档](https://docs.github.com/en/rest/gists/gists?apiVersion=2026-03-10)。

恢复由生命周期执行端串行：下载／解密／校验 → 隔离文件与配置合成 → 保存当前受管文件恢复材料 → 发布候选 → 运行时目标核心校验与既有配置应用（停止时只保存）→ 回读设置、索引及系统代理。失败分别恢复文件和凭据，并重新确认原代理；提交后的回读或代理错误带“备份已恢复”事实。相同ID仅在种类和URL一致时保留本机订阅鉴权，换源不继承旧Token。

当前验证为隔离归档、模拟GitHub API、恢复补偿及GPUI交互，未上传用户真实数据；真实GitHub权限、三平台安全凭据和真实服务内核恢复需另行验收。本地文件备份管理现已另接维护入口，复用同一归档与恢复工作流，见[补全记录](local-backup-and-parity.md)。
