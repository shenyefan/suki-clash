# 按钮与菜单检查记录

## 规范与实现

- 标准操作按钮使用左图标、右文字；图标按保存、取消、恢复、导入、导出、刷新、安装、修复、卸载等语义选择。
- 字段右侧辅助操作使用原生 ghost 纯图标按钮，保留可访问名称与焦点；环境变量复制只显示 Copy 图标。独立维护操作及弹窗提交保留图标和文字。
- 内核异常状态合并为 CircleAlert 与状态文字的 ghost 按钮，点击继续使用原错误 toast，不打开错误弹窗。
- 应用更新入口合并到应用版本行；版本号位于检查更新按钮左侧。目录、诊断、运行配置等文案精简。
- 操作菜单补齐语义图标；配置、节点选择、排序及筛选选项保持文字与原生选中标记。具体产品规则维护在 DESIGN.md。

## 源码检查范围

检查应用壳、仪表盘、代理组及链式代理、订阅与覆写、订阅增强与编辑器、连接与规则、日志、DNS、嗅探、内核、外部资源、系统代理、虚拟网卡、通用设置，以及共享弹窗底栏、编辑器、toast 动作和操作菜单。补齐备份、Gist、UWP、代理测速地址编辑等弹窗按钮的图标；新建 JavaScript 菜单补齐 FileCode。导航、订阅卡片、代理节点及展开组头保留其内容与选择语义，不添加装饰性操作图标。

## 验证范围与限制

- `cargo fmt --check`、差异检查和严格 Clippy（全部 targets，`-D warnings`）通过；设置相关测试 21 项、设置 schema 测试 9 项、共享弹窗测试 3 项全部通过。
- macOS 独立临时数据目录、不可用内核适配器的真实窗口检查：深色主题下的设置维护按钮、环境变量复制图标、内核异常状态与原因 toast，以及应用版本号和检查更新按钮同行布局。
- 实机检查没有启动内核、修改系统代理、路由或安装服务。临时构建入口和 Cargo 配置已清理，不添加生产预览模式。
- 未对所有弹窗逐一做真实窗口验收；浅色主题、最小窗口、Windows 与 Linux 未实机验证。源码检查和自动化测试不等同于全界面验收。
