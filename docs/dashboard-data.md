# 仪表盘统计来源对照

本页对照固定 CV dev 2.5.10（5b7e876）源码；源码核对，不代表真实平台效果验收。参考目录后续已更新至 b9ab3b20，新增变化与适用性见 [11-05 增量复核](cv-update-comparison-2026-11-05.md)，不改变本页原核对基线。

## CV 已有数据

| 指标 | CV 取得路径 | Suki 处理 |
| --- | --- | --- |
| 上传、下载速率 | `use-traffic-data.ts` → Mihomo `/traffic` WebSocket → `enhanced-traffic-stats.tsx` | 保留真实流速率与近期曲线 |
| 累计上传、下载 | 同一 traffic 响应 `upTotal/downTotal` | 当前完整 connections 快照已带 `uploadTotal/downloadTotal`；展示内核累计量，不以应用采样量代替 |
| 活动连接 | `use-connection-data.ts::useConnectionSummaryData` → count | 完整连接快照长度，流断开标未知，不把旧快照当作最新活动数 |
| 内核内存 | `use-memory-data.ts` → `/memory` → `inuse` | 由同批 memory 采集任务接入；不能展示本应用进程 RSS 当内核内存 |
| 速率曲线 | `use-traffic-monitor.ts` / `traffic-monitor-worker.ts` / `traffic-sampler.ts` | CV raw 10 分钟、压缩 60 分钟，纯内存；Suki 本批保留最近 10 分钟、最多 600 点有界会话曲线 |
| 当前节点延迟 | `current-proxy-card.tsx` / 测速接口 | 使用节点测速，不把出口 IP 查询耗时当节点延迟 |
| DNS 延迟 | 内核 `/dns/query` 实测 | 首次就绪及每次进入仪表盘时用随机子域查询计时，失败显示“—”；不是 DNS 请求统计 |

## 应移除的现有展示与应用统计逻辑

今日／本月累计、24 小时柱线图、进程／域名／策略流量排行、代理／直连流量拆分以及连接进程数拆分，在 CV 当前仪表盘没有对应采集或持久化功能。已通知父代理按用户授权删除这些展示；本文件对应 `statistics.rs` 的跨日磁盘账本、分类与排名采样已删除。现有用户 `statistics/traffic.json` 不自动删除、迁移或覆盖。

CV 的 `mihomo_traffic_date` / `mihomo_memory_date` storage key 是 WebSocket 订阅日期，不是长期流量历史。CV 当前流量图使用 Worker/inline 内存采样器，引用数归零会 stop/clear；没有本批可直接参考的日／月跨会话流量账本，因此不得把原应用自定义长期统计说成 CV 的实现。

## 原自定义统计局限（随删除逻辑消除）

- 第一个累计快照只建 baseline，跨进程累计不能并入日／月；重启采集也不等于恢复完整内核流量。
- 只有在两次连接快照均存在的连接才能准确归因，采样间已关闭的连接只归为未分类；新连接全量累计还受总量余量截断，排名并非完整实际排行。
- 840 个有数据小时的截断不是严格 35 个自然日；8 MiB 上限还会清空全部排名，展示不能作为精确历史。
- 用后一个采样时间归属跨小时／午夜差值，不能断言小时分配精确。

## 本批代码

`src/overview/statistics.rs` 现只保留连接反序列化模型、实时 Summary（upload_rate/download_rate/connections/rates）及内存 Recorder。Recorder 无磁盘依赖，无 load/save/sample/summary，不再维护无用户需要的分类账本；流中断调用 gap，清空曲线并等待真实样本，不填零补造缺口。新增最低层测试检查时间窗口淘汰、速率点上限和断流后无伪造补点。

## 页面调整

顶部只保留外部 IP 及显隐、刷新。IP 国家／城市／ASN／运营商／时区／经纬度移至页面下方；实时指标随后展示，配置／节点／模式在统计区下方。内存使用私有 /memory 流，复用有限重连、心跳、有界刷新与代次隔离。节点延迟来自来源绑定的测速结果，失败、超时和未测分别展示，不使用 IP 探测耗时替代。

没有实现 CV 未提供的日／月持久账本或 DNS 请求统计。原磁盘统计文件保留，不自动删除或迁移。

## 验证

全量隔离回归 350 项通过、16 项忽略；新增两项内存解析／断流／代次回归，近期速率窗口／上限／断流回归两项通过。严格 Clippy 通过。macOS 隔离窗口检查了无内核时的完整仪表盘与 IP 位置；数据填充图表的最小窗口布局由现有 GPUI 回归覆盖。未启用真实系统代理或 TUN；真实内核长期运行、三平台窗口和性能验收另行进行。

## 用户后续调整

按用户要求恢复原有左右分区卡片与上方配置／当前节点／出站模式控制行。恢复代理／域名／进程排行，作为 Suki 明确的产品功能；它不依赖 CV 是否有对应卡片，只统计当前内核生命周期内已观察连接差值，重复快照不重复计数，断流不追补未知时段，重启或停止清空；不写磁盘。移除 IP 自动刷新偏好与 300 秒周期，每次进入仪表盘通过独立监测通道刷新，首次内核就绪探测保留。
