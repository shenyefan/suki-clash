# 日志

内核与程序分别保存到应用数据目录的 `logs/`，文件前缀为 `core-` 和 `program-`。

- 内核页：内核日志级别、文件大小、保留天数。级别应用到 Mihomo；运行与校验进程的输出均记录。
- 设置页：程序日志级别（默认 Info）、单文件 KB、文件数量及清理周期。设置即时保存并应用，程序设置不影响内核日志。
- Error：操作失败及日志保存失败；Warning：可恢复异常或未支持的操作；Info：生命周期与业务结果；Debug：常规保存、目录及文件操作；Trace：细粒度诊断。所选级别包含更严重级别，Silent 停止常规程序日志。
- 来源显示内核消息的 `[TCP]`、`[DNS]` 等前缀，未标记的输出显示 `mihomo`；程序显示 `core`、`settings`、`profiles`、`overrides`、`storage` 等模块。
- 后台按来源保留最近 1000 条实时记录，界面每 150 ms 批量读取。文件保留独立于界面缓冲、暂停和清空操作。
- 默认按时间倒序，时间相同时按记录序号排序。来源、排序、筛选、搜索和暂停不保存到设置文件。
- 内核凭据在发布和保存前统一脱敏。过长日志整行丢弃并记录警告，跳过后续片段，直到换行恢复。
- 文件写入失败在程序日志及错误 toast 报告；内核管道继续读取，避免堵塞子进程。无法写盘时的错误仍保留在实时缓冲中。

自动化验证覆盖日志解析、分级筛选、分卷及文件数量、设置热更新、脱敏、过长行、来源隔离、默认排序、详情宽度和不保存浏览状态。原生窗口的手动验收另行记录。

程序错误由产生边界直接传播，批量和并行任务合并相同原因；不重复模块前缀或逐层添加失败文案。测速正常完成与图标缓存就绪记录 Debug，批次失败记录 Warning。实时刷新恢复选中身份不触发定位，保留用户滚动位置。
